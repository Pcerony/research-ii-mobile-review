# A Study on Co-creation Tools for Designing Interpretive Signage · 瑞士风 PPT 项目记录

## 视觉设定

- 风格：瑞士国际主义 / Swiss Style；封面保留原点阵呼吸场，仅在右侧周期性显现花朵点阵图案
- 主题色：森林绿 Forest Green
- 输出：单文件 HTML 横向翻页 PPT，入口 `ppt/index.html`
- 图片目录：`ppt/images/`
- 页数：19 页，分为 6 个章节：研究背景、研究设计、方法与工具、结果概览、研究发现、讨论与结论。
- 画布：单页固定 4:3（1200 × 900 逻辑像素），根据视口等比缩放。
- 放映模式：中央完整显示当前页，左右保留前后页的边缘预览；点击预览可翻页。
- 顶部指示器：上方显示章节时间线，下方 footer 显示当前页标题和总页码；不显示全宽进度条。
- 内容原则：每页保留一个核心结论与一组证据，隐去重复页头、长公式说明和冗余帮助文字；正文完整显示，不使用文本截断。
- 第 2、3 页：左侧保留单层标题与正文，右侧使用主图承载现场证据；不再使用嵌套标题卡片。
- 卡片原则：中性白/灰内容块降级为开放式分组，仅保留一条分隔线；强调色、深色、数据图表和实际图片容器继续作为有意的独立表面。
- ESC 目录：19 页缩略图使用 4 列 × 5 行网格，确保最后 3 页也保持完整可用的卡片高度。

## 口径

- 现场实验：2025 年 5-6 月，福冈市植物园温室区域，招募真实来园者 15 名，年龄 20-80 岁。
- 本次 Quick Data / AOI 分析：以 9 名参与者的修正后热力图为有效样本；总实验样本为 15 名。
- “完读率”在本 PPT 中统一表述为“文字区域视线覆盖率”，不是主观读完或理解率。
- AOI 阅读率表述为“热力强度相对注意分配”，不是严格 fixation duration。

## 多语言 (i18n) 维护规则

本项目支持四语切换：中文 (zh)、英文 (en)、日文 (ja)、西班牙语 (es-MX)。

### 强制要求

1. **任何在 HTML 中新增或修改的中文字符串，必须在三个语言包中同步添加翻译。**
   - 语言包位于 `ppt/index.html` 中的 `const LANGUAGES` 对象（约第 3100 行起）
   - 三个需要维护的语言块：`LANGUAGES.en.strings`、`LANGUAGES.ja.strings`、`LANGUAGES['es-MX'].strings`
   - 键为原始中文文本（trim 后），值为对应语言的译文

2. **修改幻灯片 HTML 文本时，必须同时更新对应的翻译 key。**
   - 如果改了中文原文，旧的翻译 key 将不再匹配，需要在三个语言块中同时更新

3. **提交前检查清单：**
   - [ ] 新增/修改的每个中文字符串在 `LANGUAGES.en.strings` 中有对应 key
   - [ ] 新增/修改的每个中文字符串在 `LANGUAGES.ja.strings` 中有对应 key
   - [ ] 新增/修改的每个中文字符串在 `LANGUAGES['es-MX'].strings` 中有对应 key
   - [ ] 翻译内容与页面实际显示的文本完全一致（trim 后匹配）

### i18n 系统原理

- `captureI18nTargets()` 通过 TreeWalker 遍历 `#deck` 内所有文本节点
- `applyLanguage(lang)` 对每个目标文本节点：
  - zh → 恢复原始 nodeValue
  - 其他语言 → 在 `LANGUAGES[lang].strings` 中查找完全匹配的 key，找到则替换，未找到则保留原文
- HTML 中文原文即为翻译字典的 key，无需额外的 key/ID 字段

### 翻译操作步骤

1. 修改 `ppt/index.html` 中的 HTML 文本
2. 在 `LANGUAGES.en.strings` 末尾（`}` 之前）添加 `"原文": "英文翻译",`
3. 在 `LANGUAGES.ja.strings` 末尾添加 `"原文": "日文翻译",`
4. 在 `LANGUAGES['es-MX'].strings` 末尾添加 `"原文": "西班牙文翻译",`
5. 确保各语言块的最后一个条目结尾有逗号（与其他条目一致）

## 运行时与显示回归（强制）

单文件 HTML 的内联运行时负责语言切换、幻灯片包裹、轮播定位和响应式几何计算。任何一个内联脚本的语法错误都会让这些初始化步骤全部跳过，页面随后会退回到源码默认的左上角固定画布，表现为幻灯片被裁切、错位或只露出邻页。因此，修改任意幻灯片内容、翻译或共享样式后，必须按顺序执行：

```bash
node test/check-runtime-contract.js
node test/check-slide-display.js
node test/check-focused-deck-browser.js
node test/check-slide-2-3-browser.js
```

- `check-runtime-contract.js` 验证所有非 module 内联脚本可解析，并在失败时报告脚本对应的 HTML 起始行。
- `check-slide-display.js` 覆盖 `2048×1086`、`1440×1000`、`900×900`、`390×844`，验证当前页存在、保持 4:3、完整落在视口内且无浏览器运行时错误。
- 如果第一项失败，先修复 JavaScript / i18n 词典语法，再排查 CSS 位置；不要用 `top`、`scale` 或 `overflow` 规则掩盖启动失败。
- 翻译 key 中包含 ASCII 双引号时必须写成 `\"`，每个语言块插入新条目前必须保留上一条末尾逗号；可由脚本生成的词典优先使用 `JSON.stringify`，不要手写未转义的 JS 对象片段。
