# 来源与文件边界

## 本项目内的目录角色

| 目录 | 角色 | 是否可编辑 |
|---|---|---|
| `00_项目管理/` | 规则、口径、证据账本、计划、日志、QA | 是 |
| `00_口径与来源/` | 迁移时保留的结构化控制快照 | 默认只读 |
| `01_主稿参考/` | 当前主稿和最终投稿参考 | 否，复制使用 |
| `02_证据/` | claims、来源元数据、实验数据和现场记录 | 否，原样保存 |
| `03_图表与素材/` | 图表、现场照片、材料及热图原件；部分热图像素含身份 | 否，原样保存，不直接公开原热图 |
| `04_PPT工作区/` | PPT 源文件、页面草稿、演示所需本地资源 | 是 |
| `05_输出/` | PDF、截图、检查结果和压缩包 | 可重建 |

## 来源分级

### A 级：本地可直接追溯

`02_证据/` 和 `03_图表与素材/` 中的实际文件，以及 `01_主稿参考/` 中的稿件参考。

### B 级：本地 provenance 记录

`02_证据/sources_数据源元数据.yml` 中的 `materials/...` 路径和 SHA-256。它们记录
来源身份，但对应的旧材料没有复制进本独立项目；不能把不存在的本地文件当作已核验来源。

### C 级：历史背景

旧幻灯片、历史稿、修士/博士材料、申请材料和旧项目管理文件。它们不属于本项目依赖，
也不应被 PPT 直接引用。

## 独立性规则

- 新管理文档不得要求访问上级目录才能理解项目。
- PPT 中的素材路径必须指向本项目内的相对路径。
- 证据 provenance 的旧路径只能作为说明，不能作为运行时资源路径。
- 若需要从外部重新引入文件，必须先登记文件名、来源、用途、隐私检查和 SHA-256。
- 不把新 PPT 的唯一源文件放回旧目录。

## 隐私边界

本项目只接受 P01–P09 形式的匿名样本编号。不复制或提交身份信息、申请表、成绩单、
财务材料、可识别旧参与者编号、招募卡和用户自有资料。

第三方截图/报告只使用工作区已匿名裁切副本，不根据原图姓名建立身份对照。对只读原件的必要核查不等于可以导出或上传它们。

## 当前审查权限

第三方独立审查默认只读成品、代码与证据，输出独立报告和QA截图；作者授权制作方修改时按授权实施。候选资料`00_项目管理/外部候选资料_待核验/`不进入当前统计，U01–U04不能重新编号为P10等。旧路径与外部候选报告仅是provenance，不是运行依赖。

第10稿按作者提供的Google Forms只读引入匿名共通题聚合，记录于14号说明与工作区questionnaire-summary.json；不复制身份，不改02/03原件，不建立N9对应，不采用实验二屏幕结果。该摘录仅是部分题目核查，不是整份原始问卷数据备份。

管理记录是作者采用边界，不能替代证据质量判断。独立审查可对口径或其依据提出异议，但应区分作者已确认的历史事实、尚未核实的方法细节与审查者推断；不得静默改原件。
