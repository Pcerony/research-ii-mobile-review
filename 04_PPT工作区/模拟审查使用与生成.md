## Slide批注追加（D-040）

画面上方提供批注选文、框选区域、整页意见。选文只针对当前Slide的真实文字；图片内文字可用框选。拖框限制在当前页，Esc取消；点击已保存意见的位置会回到原页，恢复原语言与热图/操作步骤，并显示高亮。意见可改/删，与讲稿修改一并本机保存、JSON导出；不直接写入正式Slide或讲稿文件。

JSON仍为v2：讲稿批注用`note.anchor`，Slide批注用`note.target`。`target.type`分别为`slide-text`、`slide-region`、`slide-page`；包含0基的`slideIndex`、`language`、`state`及原尺寸/比例。选文另有页内元素路径`path`和文本`anchor`；区域另有0–1的`rect:{x,y,width,height}`。它不是截图；比例改变时回看会提示。原文无法定位时保留引用，不误挂其他文本。主/补充及来源哈希隔离规则不变，第21稿已按新deck重生正式快照与音频。

适用专项：`node --test 04_PPT工作区/review-slide.test.cjs`、`node 04_PPT工作区/verify-review-slide.cjs`，输出在`05_输出/qa/review-slide/`。当前完整性范围见工作区README；以下旧使用记录保留历史语境。

## 第8稿历史记录

入口：review.html，直接打开即可，不需要服务器。审查器使用构建时的slide快照，播放和记录意见时不改正式index.html；更新讲稿/slide后必须重新构建快照。第三方审查默认先不构建，以免覆盖冻结版本。

## 播放与审查

- 默认中文讲稿、中文画面。右上“日”仅切换画面为日文，音频仍为中文。
- 播放/暂停、上一段、重听当前段、下一段；进度条可跨段定位，语速0.75至1.5倍。
- 右侧讲稿按段跳转。第12页四步对应第12–15段，随音频切换图文，步骤按钮可手动预览。第18段（第15页）展示九人热图，按音频进度切换P01、P04、P08；它们不是前10秒定量图。
- 审查页由音频控制翻页，iframe内滚轮、滑动和翻页方向键不再改变页序；正式网页的翻页功能不受影响。步骤页的左右键、Home/End仍可选择步骤。
- “记意见”暂停音频，并锁定当时页码、段号及音频位置。保存后可点击位置重听，或删除单条意见。
- 意见保存在当前浏览器本机localStorage；受浏览器限制或清理后可能丢失，提供JSON导出。不同稿件/slide版本按哈希隔离保存。

## 音频与限制

本机普通话Tingting，生成速率190；当前第8稿25段PCM WAV总长463.086秒，约7分43秒。此为合成音频长度，不是日文十分钟的发表实测，也不保证自然人朗读相同时长。分段切换可能有短暂加载间隙。

不朗读标题、配额、编辑说明。百分数在合成时展开为“百分之”，AOI分开读字母，软件名调整为可读英文；原讲稿文本和研究数值不改变。没有上传稿件到第三方服务。

正式slide与讲稿仍受原项目证据边界约束，模拟播放不是科研审查通过。新增审查界面在窄屏关闭切页过渡，以免缩放时内容临时偏移；正式页不修改。

## 更新与验证

讲稿或slide更新后：

```sh
node 04_PPT工作区/build-review.cjs
node --test 04_PPT工作区/review-core.test.cjs
NODE_PATH=[LOCAL_PATH_REMOVED] node 04_PPT工作区/verify-review.cjs
```

构建依赖本机say与afconvert；音频放assets/rehearsal，按文本/声音/速率哈希缓存。review-data.js包含25段映射、四步提示与正式页快照，避免file协议fetch跨域；review-audio-manifest.json记录讲稿、slide、音频哈希和实测音频时长。

核心逻辑review-core.js，播放及笔记review.js，外观review.css。当前QA及截图在05_输出/qa/review-v2，该目录名不是讲稿版本号。生成时检查WAV有数据且非全零；浏览器逐段解码、播放与自动翻页验证，不代表已由真人逐句听校。四步专项QA在workflow-v8，当前独立审查入口在`../00_项目管理/11_第三方独立审查入口.md`。
